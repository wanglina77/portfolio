## 📋 项目简介

单页面个人作品集网站，Vortek黑白灰极简风格。包含以下模块：

- **Hero** - 个人介绍 + 核心数据
- **Experience** - 工作经历时间线（3家公司）
- **Education** - 教育背景（北京理工大学MBA + 唐山学院）
- **Projects** - 6个项目案例展示（异形卡片交互）
- **Capabilities** - 技能能力环（产品/AI/数据/管理/工具/商业）
- **Contact** - 联系方式

## 🛠 技术栈

- 纯 HTML/CSS/JS（单文件，零依赖）
- Vortek 极简风格（黑白灰 + 青色 #00d4ff 点缀）
- 3D 卡片轮播 + 扇形叠加图片效果
- 响应式布局
